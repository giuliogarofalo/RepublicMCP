## 🔄 Data Flow

### MCP Request Flow
```
1. Claude Desktop sends MCP request
   ↓
2. MCP Server (index.ts) receives request
   ↓
3. Tool Registry routes to institution module
   ↓
4. Institution tool prepares SPARQL query
   ↓
5. SPARQL client executes query on endpoint
   ↓
6. Results parsed and typed
   ↓
7. Response returned to Claude
```

### Example: Searching Deputies
```typescript
// 1. Claude calls tool
search_deputati({ cognome: "MELONI", legislatura: 19 })

// 2. Tool builds SPARQL query
const query = `
  PREFIX ocd: <http://dati.camera.it/ocd/>
  SELECT ?deputato ?nome ?cognome ?gruppo
  WHERE {
    ?deputato a ocd:deputato .
    ?deputato foaf:surname "${cognome}" .
    ?deputato ocd:rif_leg <http://dati.camera.it/ocd/legislatura.rdf/${legislatura}> .
  }
`

// 3. Execute on endpoint
const results = await client.query(query)

// 4. Return typed results
return {
  deputati: results.map(r => ({
    uri: r.deputato,
    nome: r.nome,
    cognome: r.cognome,
    gruppo: r.gruppo
  }))
}
```

## 🌍 Ontology Differences

### Camera vs Senato

| Feature | Camera (OCD) | Senato (OSR) |
|---------|--------------|--------------|
| **Surname Field** | `foaf:surname` | `foaf:lastName` |
| **Legislature** | Full URI | Integer |
| **Date Format** | YYYYMMDD | ISO 8601 |
| **Endpoint** | dati.camera.it | dati.senato.it |
| **Group Prefix** | `ocd:` | `ocd:` (shared) |

### Common Prefixes
```sparql
# Shared
PREFIX foaf: <http://xmlns.com/foaf/0.1/>
PREFIX dc: <http://purl.org/dc/elements/1.1/>
PREFIX dcterms: <http://purl.org/dc/terms/>

# Camera-specific
PREFIX ocd: <http://dati.camera.it/ocd/>
PREFIX bio: <http://purl.org/vocab/bio/0.1/>

# Senato-specific
PREFIX osr: <http://dati.senato.it/osr/>
PREFIX xsd: <http://www.w3.org/2001/XMLSchema#>
```

## 🐛 Common Issues

### SPARQL Endpoint Timeout
```
Issue: Query takes too long
Solution:
1. Add LIMIT to queries
2. Increase SPARQL_TIMEOUT
3. Use more specific filters
```

### Missing Results
```
Issue: Query returns empty results
Solution:
1. Verify legislature number is correct
2. Check name spelling (case-sensitive)
3. Verify data exists for that period
4. Check SPARQL syntax in query builder
```

### MCP Server Not Found
```
Issue: Claude can't find MCP server
Solution:
1. Verify claude_desktop_config.json path
2. Use absolute path to dist/index.js
3. Rebuild with npm run build
4. Restart Claude Desktop
```

All SPARQL results are strongly typed:

```typescript
// Camera Deputy type
interface Deputato {
  uri: string;
  nome: string;
  cognome: string;
  gruppo?: string;
  mandati?: Mandato[];
}

// Senato Senator type
interface Senatore {
  uri: string;
  nome: string;
  lastName: string;  // Note: different from Camera
  legislatura: number;
}
```
